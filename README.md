# Obfuscator-Samples

Colección de muestras y notas sobre ofuscadores de Lua. Cada carpeta conserva el material asociado a una herramienta o fuente concreta; el contenido no pretende ser una biblioteca lista para producción.

## Contenido

- `Devlyx/` contiene una muestra Lua.
- `Goofyscator/`, `LuaObfuscator/`, `Luraph/` y `WeareDevs/` contienen sus notas o README de referencia.

El repositorio sirve para comparar estructuras y documentar procedencias. Las muestras deben tratarse como código no confiable: no las ejecutes fuera de un entorno aislado y revisa las licencias de cada fuente antes de redistribuirlas.
